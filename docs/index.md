# سياسات الخصوصية — منصة خلا (KHALA)

منصة خلا تضم مجموعة من التطبيقات المستقلة التي تشترك في نفس البنية التقنية ومعايير حماية البيانات. اختر التطبيق للاطلاع على سياسة الخصوصية الخاصة به:

- [قادر (Qader)](privacy/qader) — تطبيق التطوير الذاتي والتدريب
- [فرح (Farah)](privacy/farah) — منصة تنظيم المناسبات والاحتفالات الذكية
- [روعة (Roaa)](privacy/roaa) — منصة الاقتصاد الإبداعي بالذكاء الاصطناعي
- [حاضر (Hader)](privacy/hader) — مركز خدمات المباني الذكي
- [ولفة (Walfa)](privacy/walfa) — منصة السفر الذكية
- [درب (Darb)](privacy/darb) — منصة السيارات الذكية
- [توازن (Afia / Tawazon)](privacy/afia) — منصة الصحة والعافية الذكية
- [بصمة غيث (Ghayt)](privacy/ghayt) — منصة الأثر المستدام والعطاء الذكي
