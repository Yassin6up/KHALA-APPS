# Play Console Store Listing Drafts — KHALA Apps

Ready to paste into each app's Play Console. Three separate places per app:
1. **Store presence → Main store listing** — app name, short/full description (Character limits: App name ≤30, Short description ≤80, Full description ≤4000)
2. **Store presence → Store settings** — category (field is literally labeled "الفئة"), and "تفاصيل الاتصال في بطاقة بيانات المتجر" (email + website)
3. **Policy → App content → Privacy policy** — the URL field labeled "عنوان URL "سياسة الخصوصية""

All contact emails use `privacy@khalaapps.com`. Website field reuses the privacy policy URL (no dedicated marketing site per app yet). Category names below are copied exactly from Play Console's own Arabic dropdown (some differ from the literal translation — e.g. Play Console calls "Lifestyle" **"نمط حياة"**, not "أسلوب الحياة").
